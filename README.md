# Student Grade Calculator

## Project Description
This is a Student Grade Calculator built using HTML, CSS, and JavaScript. It allows users to enter a student's name and three assessment scores, then calculates the total score, average score, grade, and pass/fail status. The application also stores records using Local Storage.

## Features
- Enter student name
- Enter three assessment scores
- Calculate total score
- Calculate average score
- Assign grades (A–F)
- Display pass/fail status
- Display all student records
- Delete student records
- Save records using Local Storage

## How to Run
1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click on `index.html`.
4. Click **Open with Live Server**.Project developed for Introduction to Software Development Mini Project.
